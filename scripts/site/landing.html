How it works · Relate is the engine

Delete, re-run, roll back. Hundreds of times a second.

Every trial is a transaction

Delete a set of relationships inside a Relate transaction, re-run your query, compare, roll back. Only deletions that keep the answer are applied, on a scratch copy; the source is never opened for writing.

begin_transaction · rollback_transaction

Same loop and query, one machine, median of 3 runs, identical answers. It measures this setup (Docker VM, Bolt round trip), not a limit of Neo4j.

EXPLAIN prunes first

Witness collects the labels and types named in the query and in Relate's EXPLAIN plan. :ON_CONTINENT is in neither, so {{PLAN_DROP}} relationships go in one verified step, before trial 3.
