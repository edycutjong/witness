The problem

Graph answers are taken on trust.

A reviewer cannot read 57,645 relationships. “Show the path” is not enough either: a path can include relationships that change nothing.

57,645 relationships · 3,748 nodes · air-routes, drawn: 1,565 airport pairs in frame

The agent answers from the whole graph. A path view still mixes relationships that matter with ones that do not, so a reviewer has nothing small enough to check. This is the pain Witness removes.

The question · queries/two-hub.cypher

One question, three hard parts.

NOT EXISTSOPTIONAL MATCHaggregation

// Which airports of $country have no direct flight to $dest, yet would still reach it in two flights if any one hub closed?
MATCH (a:Airport)-[:IN_COUNTRY]->(:Country {code: $country})
WHERE a.iata <> $dest
  AND NOT EXISTS { MATCH (a)-[:HAS_ROUTE]->(:Airport {iata: $dest}) }
MATCH (a)-[:HAS_ROUTE]->(hub:Airport)-[:HAS_ROUTE]->(:Airport {iata: $dest})
OPTIONAL MATCH (hub)-[:IN_COUNTRY]->(hc:Country)
WITH a, count(DISTINCT hub) AS hubs, coll.sort(collect(DISTINCT hc.code)) AS hub_countries
WHERE hubs >= 2
RETURN a.iata AS airport, hub_countries
ORDER BY airport
