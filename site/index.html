Witness · proof for an agent's answer from a graph · built on Relate

22 of 57,645 relationships are why.

When an agent answers from a graph, Witness hands back a tiny graph that reproduces the answer, and proves each relationship in it is needed.

Run it yourself

The repository opens at submission; until then the clone command does not resolve and the committed output below is the run.

$ git clone https://github.com/edycutjong/witness && cd witness
$ uv run witness demo

The committed air-routes graph (3,748 nodes, 57,645 relationships) is copied, never modified. The result below is the committed output of the same run.
